# 演示视频录制脚本

> 形式：屏幕录制（建议开启前置摄像头小窗），时长 **5～6 分钟**
> 目标：让验收老师看到「功能完整 + 业务规则真的生效 + 数据闭环 + AI 真实可用」四件事
> 本文档可直接当提词器使用：**加粗**是动作，> 引号内是可说的话

---

## 0. 录制前检查清单（不录进去，提前跑一遍）

| # | 检查项 | 命令 / 操作 | 通过标准 |
|---|---|---|---|
| 1 | 后端可启动 | `cd server && npm start` | 终端出现「TaskFlow 后端服务已启动」「数据库文件 …/server/db/task.db」 |
| 2 | 前端已构建 | `cd client && npm run build` | 生成 `client/dist`；访问 `http://localhost:3000` 出页面 |
| 3 | AI 网关可用 | 浏览器打开 `http://localhost:3000/api/ai/status` | 返回 `{"data":{"enabled":true,"protocol":"anthropic"}}` |
| 4 | 测试全绿 | `cd server && npm test` | `# pass 31` `# fail 0` |
| 5 | 演示数据到位 | `cd server && npm run seed` | 页面有 7 条任务（含 2 条逾期、1 条今天到期、1 条已完成） |
| 6 | 画面干净 | 关掉无关窗口、清空桌面通知 | 只留浏览器 + 一个终端 |
| 7 | 浏览器强刷 | `Ctrl + F5` | 确保加载的是最新构建产物 |

> 若无演示数据或数据太乱：先 `npm run seed`（脚本会写入一组含逾期 / 今天到期 / 已完成的任务）。

## 1. 开场 · 项目定位（约 25 秒）

**动作**：打开项目根目录，展示 README.md 与目录结构（`server/` `client/` `docs/`）。

> 「选题是**个人任务与进度管理系统**，我叫它 TaskFlow。它解决三件事：任务从创建到完成的全生命周期管理、进度实时统计可视化，以及用 AI 做任务规划和周报复盘。
> 技术栈是 Node.js + Express + SQLite 后端，Vue 3 + Vite 前端，AI 接的是阿里云百炼的 qwen-plus。」

**动作**：切回浏览器 `http://localhost:3000`，给首页一个 2 秒全景。

---

## 2. 启动过程（约 30 秒）

**动作**：终端里 `Ctrl + C` 停掉服务，再重新 `npm start`，让老师看到启动日志。

```bash
cd server && npm start
```

> 「后端一条命令启动，它会同时把前端构建产物托管在同一个端口上，所以只需要打开 3000 这一个地址。数据库是 SQLite 单文件，第一次启动自动建表，不需要装任何数据库服务。」

**镜头重点**：终端输出中的「数据库文件 …/server/db/task.db」这一行（后面验证数据闭环要回扣）。

---

## 3. 核心功能 CRUD（约 90 秒）

### 3.1 新建
**动作**：点「+ 新建任务」→ 填「提交数据库实验报告」/ 截止日期选一周后 / 优先级「高」→ 保存。

> 「创建后列表立刻出现新卡片，右上角统计的『任务总数』同步 +1。」

**镜头**：给统计卡一个特写（数字变化瞬间）。

### 3.2 状态流转
**动作**：点卡片左侧圆圈勾选 → 任务变已完成 → 再点一次回到待办 → 用卡片上的状态切换改到「进行中」。

> 「状态机是 待办 → 进行中 → 已完成。勾选完成的同时，完成率和右边的状态分布图会一起变，不需要手动刷新。」

### 3.3 编辑
**动作**：点「编辑」改标题和优先级 → 保存。列表与两张分布图同步更新。

### 3.4 删除
**动作**：点「删除」→ 出现「确认删除？」二次确认 → 确认。任务消失，统计数字回落。

---

## 4. 业务规则现场验证（约 80 秒）★ 评分重点

### 4.1 R-01 逾期自动识别
**动作**：编辑一条**未完成**的任务，把截止日期改成**昨天**，保存。

> 「规则是：未完成且截止日期早于今天，自动判定逾期。我把日期改成昨天——卡片马上变红、出现『已逾期 1 天』，右上角『已逾期』计数 +1。」

**镜头**：卡片变红 + 统计卡数字跳动，两个都给特写。

**动作**：再编辑一条，截止日期改成**今天**。

> 「截止日等于今天是另一种状态：橙色『今天到期』标签，和逾期区分开。已完成的任务永远不会被标成逾期。」

### 4.2 R-03 数据闭环 ★ 最关键镜头
**动作**：终端 `Ctrl + C` 停掉服务 → 重新 `npm start` → 浏览器刷新页面。

> 「现在验证数据闭环：刚才所有操作都持久化在本地 SQLite 文件里。服务重启后刷新——数据一条没丢，统计口径也完全一致。」

**镜头**：可以顺带在文件管理器里展示 `server/db/task.db` 这个文件。

### 4.3 R-04 统计实时性
> 「页面没有任何手动刷新按钮，所有增删改之后列表和统计都是同时重新请求的，这是设计上保证的一致性。」

---

## 5. 筛选 / 排序 / 搜索（约 50 秒）

**动作**：依次操作，每项停留 2～3 秒：

1. 状态 Tab 切「待办」→ 列表只剩待办，Tab 上有数量；再切「进行中」「已完成」；
2. 优先级下拉选「高」→ 可与状态叠加；
3. 排序下拉切「按截止日期」→ 点「升序 ↑ / 降序 ↓」按钮切换；
4. 切回「**智能排序**」→ 说明这是默认排序；
5. 搜索框输入关键词 → 列表实时过滤（300ms 防抖）。

> 「默认用的是智能排序：逾期的排最前面，然后高优先级优先，同优先级按截止日从近到远；**已完成的任务永远沉到列表底部**——我勾选一个试一下，它立刻掉到最后。」

**镜头重点**：勾选完成后任务自动下沉到列表底部（这是 R-05，很多同学会漏）。

---

## 6. 异常处理（约 40 秒）

| # | 动作 | 预期 | 要说的话 |
|---|---|---|---|
| 1 | 新建任务时标题留空直接提交 | 前端红字「任务标题不能为空」，不发请求 | 「前端先校验，后端还有一层兜底」 |
| 2 | 快速连点「创建任务」两次 | 只产生一条任务 | 「靠 client_token 幂等令牌，重复提交返回已存在记录，不会产生脏数据」 |
| 3 | 开发者工具 Network 面板，看一个非法请求 | 400 JSON `{error:{message:...}}` | 「错误统一走错误中间件，返回结构化 JSON」 |
| 4 | 访问不存在的任务 id | 404 JSON | 「删除/更新不存在的资源返回 404，前端列表同步移除」 |

---

## 7. AI 扩展（约 100 秒）★ 评分重点

**动作**：先把浏览器切到 `http://localhost:3000/api/ai/status`。

> 「AI 是可选扩展。这个接口返回 enabled 为 true 表示网关已配置，protocol 是 anthropic——我接的是阿里云百炼的 qwen-plus。」

### 7.1 AI 任务规划
**动作**：点右下角悬浮「AI 助手」（可顺带拖一下展示可拖拽 + 双击复位）→ 弹窗 → 输入「两周内完成课程大作业」→ 生成。

> 「输入一句模糊目标，AI 拆解成带截止日和优先级的子任务。每条的标题、日期、优先级我都能现场改，不需要的就取消勾选。」

**动作**：取消勾选 1 条 → 修改某条的优先级 → 点「一键创建 N 条任务」。

> 「点创建后走批量接口，列表新增多条，统计总数同步增加。」

**镜头重点（幂等）**：**连点两次「一键创建」**，然后说：

> 「同一批结果连点两次不会重复落库——批量接口给每条子任务都带了幂等令牌，第二次返回的 duplicated 数量就等于这批任务的条数。」

### 7.2 AI 周报总结
**动作**：切到「AI 周报总结」Tab → 生成。

> 「周报不是模板填空，它喂给模型的是我真实的统计口径、近 7 天新增清单、完成清单和逾期清单，并且提示词明确要求引用真实数据、不许编造。」

**镜头**：朗读其中一句（指着屏幕读，证明是真实数据而非套话）。

**动作**：依次点「Word（.doc）」「Markdown（.md）」导出 → 打开文件展示排版。

> 「导出支持 Word、Markdown 和纯文本，也可以一键复制。导出是在浏览器本地生成的，不依赖后端，断网也能用。」

### 7.3 AI 降级（可选，15 秒）
若时间允许，可临时把 `server/.env` 改名后重启，展示弹窗内的 502 提示：

> 「网关不可用时只影响这两个 AI 按钮，任务管理的核心功能完全正常。」

> 注意：演示完记得把 `.env` 改回来并重启。

## 附：翻车预案

| 可能情况 | 处理 |
|---|---|
| 端口 3000 被占用 | 换个端口启动：`PORT=3001 npm start`，或 `netstat -ano \| findstr :3000` 找到 PID 结束掉 |
| 前端没更新 | `npm run build` 后 **`Ctrl + F5` 强刷**；必要时手动删 `client/dist` 再构建 |
| AI 生成慢 / 超时 | 弹窗内点重试；或先跳过，演示降级提示，说明不影响核心功能 |
| AI 返回内容不合规 | 后端有解析重试兜底；仍失败会提示「AI 返回内容不是合法 JSON，请重试」 |
| 数据太乱不好看 | 重新 `npm run seed` 灌一组干净的演示数据 |
| 服务起不来 | 先 `node --check` 检查改动过的文件；再看终端报错 |
